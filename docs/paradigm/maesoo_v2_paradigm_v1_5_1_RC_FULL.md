# Part 3. 1군/2군 시스템 (v1.5 핵심)

## 1군 (Maximum Conviction)

```
[외부 표시] "1군 관찰 후보"
[의미] 4게이트 모두 PASS + 치명 함정 0개
[신뢰] 매우 높음
[빈도] 월 0~3개 (희소성이 가치)
[책임] 시스템이 강하게 책임

[1군 자격]
- 게이트 1: PASS (펀더멘털 우량주)
- 게이트 2: PASS (검증 가능한 상승 촉매)
- 게이트 3: PASS (회복 또는 강세 지속)
- 게이트 4: PASS (기회비용 우위)
- 치명 함정 (C, I, B, F 중대): 0개
- 보조 함정 (D, H, J): 기록 허용
- F3 강함 (거대 외부 호재 명확)
```

## 2군 (Notable Watch)

```
[외부 표시] "2군 관찰 후보"
[의미] 게이트 1 MANUAL_REVIEW (회복 진행 중) + 게이트 2,3 PASS + 5중 필터 PASS
[신뢰] 중간 (사용자 판단 필요)
[빈도] 월 5~15개
[책임] 사용자가 판단

[2군 자격]
- 게이트 1: MANUAL_REVIEW 허용
  * 시총 $50B+
  * non-GAAP 흑자 전환 또는 흑자 진입 진행
  * 부채비율 300% 이하
- 게이트 2: PASS 필수 (촉매 검증)
- 게이트 3: PASS 필수 (회복 신호 필수)
- 게이트 4: PASS 또는 MANUAL_REVIEW 허용
- 5중 필터 (F1~F5): 모두 PASS
- Hard Negative: 없음 (active+material+unresolved 0개)
```

## 탈락 조건

```
- 게이트 1 FAIL (적자 + 부채 폭탄, 예: CRWV)
- 5중 필터 1개 이상 FAIL
- 치명 함정 식별 (1군 기준)
- Hard Negative active (2군 기준)
- ENTRY_BLOCK (D STRONG + H STRONG)
```

# Part 4. 4게이트 시스템 (v1.5 핵심)

## 게이트 상태값 (4종)

```
PASS              명확히 통과 (모든 조건 충족)
FAIL              명확히 탈락 (1개 이상 명백히 실패)
INSUFFICIENT_DATA 데이터 부족, 판정 불가 (후보 제외)
MANUAL_REVIEW     자동 판정 모호, 사람 검토 필요
```

**알림 발송 기준:** 4게이트 모두 PASS여야 함 (1군).
2군은 게이트 1 MANUAL_REVIEW 허용.

## 게이트 1: 펀더멘털 (Quality Floor)

```
[목적] 망할 위험 없는 회사만 통과
[철학] 좋은 회사 고르기 X, 나쁜 회사 거르기 O

A. 규모 임계값
   - 시가총액 $10B+ (미국 대형주)
   - 한국: KOSPI 200 또는 시총 5조원+

B. 재무 건전성
   - ROE 15%+
   - 부채비율 200% 이하
   - 영업이익 흑자 (최근 4분기 누적)
   - 보조: 영업이익 vs 순이익 갭 30%+ → 일회성 의심 → MANUAL_REVIEW

C. 사업 지속성
   - 업력 10년+
   - 또는 명확한 시장 지배력 (점유율 top 3, 섹터 시총 top 5)

D. 거래 유동성
   - 일평균 거래대금 $50M+

[섹터별 예외]
은행: 부채비율 면제, BIS 자기자본비율 10%+, NPL 3% 이하
보험: 부채비율 면제, RBC 200%+
리츠: ROE/부채비율 면제, FFO 안정성, LTV 60% 이하
유틸리티: ROE 면제, 배당 안정성 (10년 연속)

[부채비율 데이터 정의 고정]
표준: Total Debt / Shareholders' Equity
단위: 비율 (0.5 = 50%, 5.0 = 500%, 10.7 = 1,070%)
음수 자기자본 / 결측 → INSUFFICIENT_DATA (FAIL 아님)
```

## 게이트 2: 검증 가능한 상승 촉매

```
[목적] 과거 영광 + 미래 모멘텀 부재 함정 거름
[철학] 펀더멘털 좋아도 상승 가설 검증 가능 근거 필수

[3가지 패턴]
A. 일시적 외부 충격 (Mean Reversion)
   예: 코로나 항공주, 금리 인상기 부동산리츠
B. 명확한 촉매 (Catalyst-Driven)
   예: 인텔 정부 보조금, 신약 승인
C. 구조적 전환 (Structural Shift)
   예: AI 반도체, EV 전환, 비만치료제 (LLY)

[호재 가중치 4단계]
즉시 매출 호재 (2.0): FDA 승인+출시, 대형 정부 계약, 신제품 출시 후 매출 확인, M&A 발표 (인수기업 측)
펀더멘털 호재 (1.5): 어닝 서프라이즈, 가이던스 상향, 컨센서스 상회
전략 호재 (1.0): 파트너십 (R&D), AI 전환 발표, 신사업 진입, 임상 진행
주주환원 호재 (0.5): 자사주 매입, 배당 인상, 주식 분할

노이즈 (0): 일반 사업 헤드라인, 분석가 단순 의견, 컨퍼런스, 광고

[출처별 가중치]
공식 (SEC/회사 공시): × 1.0
대형 미디어 (Bloomberg/Reuters/WSJ): × 0.8
일반 뉴스: × 0.5
블로그/소셜: × 0.3 또는 무시

[통과 조건]
가중 합산 점수 3.0+ (최근 3개월)

[부정 이벤트 가중치 - materiality-weighted]
Hard Negative (2.0): 정부 가격 인하 명령, Medicare 협상, 가이던스 cut, 경쟁사 압도적 성장
규제·소송 (1.5): FDA 경고, 반독점 조사, 행정 제재, 환경/안전 소송
펀더멘털 악재 (1.5): 어닝 미스, 가이던스 미달, 조정 기준 -5%+
노이즈 (0.5): 일반 우려, 단순 의견 하향

[Hard Negative 단독 룰 - v1.4.1 결함 보강]
"1개라도 있으면 FAIL" X
"active + material + unresolved 3조건 모두 충족 시 FAIL"

[M&A 이벤트 주체 구분]
인수기업: 호재 후보 가능
피인수기업: 함정 C (이벤트 종료) → Step 1에서 manual_exclusion

### Recovery Track (회복 트랙)

```
[타겟] 큰 하락 후 바닥 다지고 회복 시작 (예: 인텔 2024Q4)

[통과 조건 - 모두 충족]
R-A. 하락 상태: 52주 고점 대비 -20% 이상 하락
R-B. 회복 시작: 6개월 저점 대비 +15% 이상 상승
R-C. 추세 전환: 50일 이평선 > 200일 이평선 (또는 골든크로스 임박)
R-D. 거래량 증가: 최근 1개월 평균 거래량 > 6개월 평균 거래량

[거름 대상]
- NVO: R-B 미달 (회복 시작 신호 없음)
- 네이버/카카오: R-C 미달 (추세 전환 신호 없음)

[잡는 대상]
- 인텔 (2024Q4): R-A, R-B, R-C, R-D 모두 충족
```

### Continuation Track (지속 트랙)

```
[타겟] 강세 지속 중 얕은 조정 후 재상승하는 주도주 (예: LLY)

[통과 조건 - 모두 충족]
C-A. 얕은 조정 상태: 52주 고점 대비 -3% ~ -15% 범위
C-B. 강세 추세: 50일 이평선 > 200일 이평선 (명확)
C-C. 재상승 시작: 최근 1개월 +3% 이상 상승
C-D. 거래량 증가: 최근 1개월 평균 > 3개월 평균
C-E. 강화 조건: 게이트 2의 3개 조건 (호재 누적 + 어닝 트렌드 + 애널리스트 의견) 모두 PASS

[C-E 강화 이유]
- Recovery는 게이트 2의 2개 조건만 충족해도 OK
- Continuation은 "이미 오른 종목" 받으므로 더 엄격
- 안 그러면 NVDA 같은 고점 추격이 통과해버림

[거름 대상]
- NVDA (고점): C-A 미달 (52주 고점 -3% 미만, 너무 강세)
- 네이버/카카오: C-B 미달 (강세 추세 없음)

[잡는 대상]
- LLY: C-A, C-B, C-C, C-D, C-E 모두 충족
```

| **C** | 이벤트 종료 (M&A, 상장폐지, 거래정지) - 즉시 제외 |
| **I** | active Hard Negative (가격 인하 진행, 정부 조사, 회계 부정) |
| **B** | 구조적 약화 (NVO 같은 매출 -5% + 경쟁사 압도) |
| **F-중대** | 중대 회계/법무 리스크 (DOJ 회사 직접 기소, 감사의견 거절) |

치명 함정 1개 이상 식별 시 → 1군 자격 X. 2군 자격도 신중 검토.

### 보조 함정 (1군 자격 유지, 기록만)

| 함정 | 정의 |
|---|---|
| **D** | 고점 추격 부담 (52주 고점 -3% 이내) - 강한 종목 보통 해당 |
| **H** | 멀티플 압축 위험 (단, 영구 압축 단정 X) |
| **J** | ADR/환율 보조 리스크 (scope exception) |
| **F-경미** | 일회성 항목 (실적 착시 의심 약함) |
| **G** | 목표가 vs 추정치 괴리 (데이터 단위 검증 필수) |
| **A** | 가치 함정 (단, 호재+회복 신호 있으면 보조) |
| **E** | 저변동 (성숙 대형주 보통 해당) |

보조 함정 식별 시 → 기록만, 1군/2군 자격 유지.

### 원칙

```
- 1군은 치명 함정 0개 + 보조 함정 모두 기록
- 2군은 치명 함정 0개 + 보조 함정 일부 허용
- 함정 분류는 시뮬레이션/실전 운영에서 명확히 표기
```

## 함정 충돌 우선순위

한 종목이 여러 함정에 동시에 걸릴 때 처리 순서:

```
우선순위 1: C (이벤트 종료) [치명]
  → manual_exclusion_list 즉시 제외, 게이트 안 탐

우선순위 2: I (규제/소송 진행 중) [치명]
  → 게이트 2 FAIL 또는 MANUAL_REVIEW
  → 펀더멘털 양호해도 진행 중 부정 이벤트가 우선

우선순위 3: B (구조적 약화) [치명]
  → 게이트 3 FAIL + 게이트 4 FAIL
  → NVO 같은 케이스

우선순위 4: A (가치 함정) [보조] / H (멀티플 압축) [보조]
  → 게이트 2 FAIL + 게이트 4 보조 체크
  → 네이버/카카오 같은 케이스

우선순위 5: D (고점 추격) [보조]
  → 게이트 3 Continuation C-A 미달 또는 게이트 4 함정 H

우선순위 6: F (실적 착시) / G (목표가 함정) / E (저변동) [보조 - 단 F-중대는 치명]
  → 보조 체크 신호, 자동 거름

우선순위 7: J (ADR/환율) [보조]
  → scope exception, Phase 1 진단용
```

### 원칙

```
- 높은 우선순위 함정이 식별되면 즉시 제외
- 낮은 우선순위 함정은 보조 신호로 활용
- 여러 함정 동시 식별 시 모두 기록 (디버깅/검증용)
```

  ↓ 약 9,950 → 500~800 종목

  ↓ 약 500~800 → 50~150 종목
  
Step 4: 게이트 3 (회복 신호 - 2트랙)
  ↓ Recovery Track 또는 Continuation Track 중 1개 PASS
  ↓ 약 50~150 → 10~30 종목

  ↓ Peer group 자동 선정
  ↓ 4개 그룹 비교 (수익률/밸류에이션/펀더멘털/모멘텀)

Step 7: watchlist_log 동적 추적
  ↓ 매주 자동 재평가 (즉시 이벤트 발생 시 트리거)

  ↓ 조건 이탈 시 "관찰 후보 해제" 알림
```

# Part 17. 검증 시뮬레이션 양식 (Phase 1용)

## 블라인드 테스트 5대 원칙

Phase 1 시뮬레이션 시 반드시 지킬 5가지. 안 지키면 시뮬레이션 자체가 사후 정당화.

```
1. 결과를 보고 기준을 끼워 맞추지 마라
   - 게이트 조건은 시뮬레이션 시작 전 고정
   - 시뮬레이션 도중 임계값 조정 금지
   - 조건 수정이 필요하면 시뮬레이션 종료 후 v1.x 패치

2. 평가 시점 당시 알 수 있었던 데이터만 사용
   - 인텔 2024-10-15 시뮬레이션 시 → 2024-10-15 이전 데이터만
   - 그 이후 어떻게 됐는지 알면서 평가 X

3. 실제 이후 주가 흐름은 별도 "사후 비교" 섹션에만 기록
   - 시뮬레이션 본문에 "이후 X% 올랐다" 표현 금지
   - 사후 결과는 별도 섹션 (참고용)

4. 함정 분류 명시 (PASS/FAIL만으로 끝내지 마라)
   - 게이트 FAIL이면 어느 함정 (A~J)에 걸렸는지 기록
   - 여러 함정 동시 식별 가능 (우선순위는 Part 7 따름)

5. 소스팩 고정
   각 시뮬레이션 시작 전 사용 가능 자료를 명시적으로 고정.

   필수 기록 항목:
   - 평가 시점: YYYY-MM-DD
   - 사용 가능 자료 컷오프
   - 출처 URL + 자료 발행 날짜
   - 데이터 단위 검증 결과 (USD/DKK/EUR, 분기/연간, GAAP/조정)
   - ADR 여부 + 본주 시장
   - 제외 자료: 평가 시점 이후 발행 자료

   소스팩 고정 없이는 시뮬레이션 결과 무효.
```
